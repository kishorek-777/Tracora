## Build

**Backend**
- `tracora/hooks.py` — app metadata only. No `doc_events`, no
  `scheduler_events` yet; those arrive in P3 and P9.
- Roles `Tracora Super Admin` and `Tracora Admin`, exported as fixtures
  with an explicit name filter. Unfiltered `fixtures = ["Role"]` drags
  every role on the site into the app — do not.
- `Tracora Settings` (Single): `tag_prefix` (Data, default `TRC-`),
  `reminder_lead_days` (Data, default `30,15,7,2,1,0`),
  `label_width_mm` / `label_height_mm` / `qr_size_mm` (Float, 50/25/15),
  `sender_email` (Data), `last_reminder_run` (Datetime, read-only),
  `hrms_sync_enabled` (Check).

**UI**
- A `Tracora` workspace. Empty of content for now, but it exists and is
  visible to both roles — later phases hang shortcuts off it rather
  than inventing navigation ad hoc.
- `Tracora Settings` form grouped into sections: *Asset tags*,
  *Labels*, *Reminders*, *HRMS*. A flat nine-field settings form is a
  wall; this one is read rarely and edited rarelier, so it should
  explain itself.
- Each settings field gets a `description` written for an admin, not a
  developer. `reminder_lead_days` says "Days before a due date to send
  reminders. Comma separated." not "csv of ints".

## Do not build

Any business doctype. Any HRMS integration. Any asset concept.
