## Architecture & Design Decisions

1. **Explicit Role Security on Every Report**:
   - Every query report must explicitly declare:
     ```json
     "roles": [
       {"role": "Tracora Super Admin"},
       {"role": "Tracora Admin"}
     ]
     ```
   - Reports do not rely on implicit doctype permissions.

2. **Strict PII Exclusion (FR-39)**:
   - Under no circumstances may any report query select `aadhaar_number` or `permanent_address`.
   - Validated by an automated grep gate over all report Python/SQL/JSON files before completion.

3. **Software Licence Dates Contract**:
   - Reports query **`licence_expiry_date`** and **`next_renewal_date`** only.
   - `payment_date` and `licence_renewal_date` do not exist and must not appear anywhere in queries, columns, or filters.

4. **Active Seats Convention**:
   - `active_seats` count on licence reports is defined as `Active + Flagged` (`seat_status IN ('Active', 'Flagged')`), consistent with FR-20, FR-86, and the document model.

5. **`next_renewal_date IS NULL` Handling**:
   - Licences with `renewal_cycle = 'One-time'` or missing `licence_start_date` have `next_renewal_date IS NULL`.
   - In **Licence Renewal Due**, the report filters `WHERE next_renewal_date IS NOT NULL` by default to preserve a clean chronological timetable.
   - A filter toggle `Include Non-Renewing / Unset Start Date` (`default: 0`) allows viewing them, sorted to the bottom (`ORDER BY CASE WHEN next_renewal_date IS NULL THEN 1 ELSE 0 END, next_renewal_date ASC`).

6. **Exited Employee Custody Surfacing (FR-77)**:
   - If an employee has `status = 'Exited'` but still holds an assigned asset, **Assets by Employee** surfaces them prominently with a red warning pill: `Exited (Custody Alert)`. They are never silently hidden.

7. **Reminder Log Metrics Scope**:
   - `Tracora Reminder Log` summary/delivery metrics are **explicitly deferred** from P10's 8 query reports. They remain accessible via the dedicated Desk List View and the Workspace Health Banner (FR-90).

## Build — Backend (The 8 Query Reports)

1. **Assets Owned** (FR-36, FR-74):
   - **Filters**: `owner_company` (Link to Tracora Company, internal only by default), `status`, `condition`.
   - **Scope**: Assets owned by `owner_company`.
   - **Columns**: Asset Tag (`asset_tag`), Asset Name (`asset_name`), Brand (`brand`), Serial No (`serial_no`), Owner Company (`owner_company`), Holding Company (`holding_company`), Branch (`branch`), Location (`location`), Status (`status`), Condition (`condition`).
   - **Chart**: Bar chart above table summarizing total owned assets by Company.

2. **Assets Held** (FR-74):
   - **Filters**: `holding_company` (Link to Tracora Company), `status`.
   - **Scope**: Everything physically in custody of `holding_company`, showing true ownership per row.
   - **Columns**: Asset Tag (`asset_tag`), Asset Name (`asset_name`), Holding Company (`holding_company`), Owner Company (`owner_company`), Assigned To (`assigned_to`), Branch (`branch`), Location (`location`), Status (`status`).

3. **Assets by Branch** (FR-36):
   - **Filters**: `branch` (Link to Tracora Branch), `company` (Link to Tracora Company), `status`.
   - **Scope**: Filtered by the asset's own branch, including unassigned stock (`status = 'In Store'`).
   - **Columns**: Branch (`branch`), Asset Tag (`asset_tag`), Asset Name (`asset_name`), Brand (`brand`), Status (`status`), Condition (`condition`), Assigned To (`assigned_to`), Location (`location`).

4. **Assets by Department** (FR-36, FR-37):
   - **Filters**: `department` (Link to Tracora Department), `company` (Link to Tracora Company).
   - **Scope**: Grouped by holder's department.
   - **FR-37 Edge Case**: Unassigned stock (`assigned_to IS NULL`) has no department and appears as a dedicated grouping/row labeled `Unassigned Stock` rather than vanishing from the report.
   - **Columns**: Department (`department`), Asset Tag (`asset_tag`), Asset Name (`asset_name`), Brand (`brand`), Status (`status`), Assigned To (`assigned_to`).

5. **Assets by Employee** (FR-36, FR-77):
   - **Filters**: `company` (Link to Tracora Company, restricted to `company_type = 'Internal'`), `department`, `employee`.
   - **Scope**: **Internal companies only.** Client and partner personnel are strictly excluded.
   - **Description**: "Covers internal company employees only. For client/partner-placed assets, see External Custody report."
   - **Exited Custody Alert**: Exited employees retaining custody are surfaced with red status pill `Exited (Custody Alert)`.
   - **Columns**: Employee Code (`employee`), Employee Name (`employee_name`), Department (`department`), Asset Tag (`asset_tag`), Asset Name (`asset_name`), Serial No (`serial_no`), Assigned Date (`assigned_on`), Employee Status (`employee_status` — SQL alias for `tabTracora Employee`.`status` to disambiguate from asset status).

6. **External Custody** (FR-77):
   - **Filters**: `holding_company` (restricted to `company_type = 'External'`), `employee`.
   - **Scope**: External counterpart to report 5. Assets placed with clients, vendors, or partner personnel.
   - **Description**: "Covers assets placed with external client and partner personnel."
   - **Columns**: Client / Partner Company (`holding_company`), Contact / Holder (`employee_name`), Asset Tag (`asset_tag`), Asset Name (`asset_name`), Serial No (`serial_no`), Assigned Date (`assigned_on`), Location (`location`).

7. **Licence Expiry** (FR-36):
   - **Filters**: `company`, `licence_type`, `licence_status` (default `Active`).
   - **Scope**: Software licences and contract expiry dates.
   - **Sorting**: `licence_expiry_date ASC` by default.
   - **Columns**: Software Name (`software_name`), Licence Name (`licence_name`), Company (`company`), Licence Type (`licence_type`), Expiry Date (`licence_expiry_date`), Days Remaining (`days_remaining`), Active Seats (`active_seats` = Active + Flagged), Status (`licence_status`).

8. **Licence Renewal Due** (FR-36, LLD §9):
   - **Filters**: `company`, `renewal_cycle`, `include_non_renewing` (Checkbox, default 0).
   - **Scope**: Upcoming renewal checkpoints driven by `next_renewal_date`.
   - **Sorting**: `next_renewal_date ASC` by default (NULLs excluded unless filter toggled).
   - **Columns**: Software Name (`software_name`), Licence Name (`licence_name`), Company (`company`), Renewal Cycle (`renewal_cycle`), Next Renewal Due (`next_renewal_date`), Days Until Renewal (`days_until_renewal`), Status (`licence_status`).
