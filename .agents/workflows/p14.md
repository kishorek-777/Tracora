# /p14 — UAT and fixes

8 dev-days, mostly other people's time. Depends on P1–P13 all reported
complete with evidence.

## Entry condition

Every acceptance list from P1 to P13 has passed **with walkthrough
evidence**. If any is still untested, this phase starts later — it does
not start with a lowered bar.

## What this phase is

Real users work real scenarios: register, assign, hand over, exit
someone with assets outstanding, print and scan a label, receive a
reminder. They will find things no acceptance list predicted, because
they will use the system in ways nobody specified.

## The agent's role

- **Fix bugs against the FR they relate to**, not against the symptom.
- **Re-run the acceptance list of whichever phase a fix touched, every
  time.** A fix to P5's assignment logic that is not re-checked against
  P5's own tests can quietly undo something P5 already proved.
- **Do not expand scope.** A genuinely new requirement gets logged for
  later. This phase makes 92 FRs work; it does not add a 93rd.

## The UI consistency pass — do this once, deliberately

Individual phases each built their own screens. Nobody has yet looked
at them together. Walk the whole app with the browser agent and check:

- **Status colours identical everywhere** — list indicators, report
  columns, form headers, PWA chips. One state, one colour, one label.
- **Action verbs consistent** — the button says Assign, the message
  says Assigned, the movement type says Assign. Not "allocate" in one
  place and "issue" in another.
- **Every refusal message names cause and fix** (rule 14). Collect them
  all and read them as a set — this is where a generic "Operation
  failed" that slipped through becomes obvious.
- **Every empty state invites an action** rather than reporting absence.
- **Every list opens with useful defaults** — no list that opens empty
  or opens with four thousand unsorted rows.
- **Section grouping consistent** across forms — a user moving between
  Asset and Licence should not have to relearn where things are.

Produce a screenshot contact sheet of every major screen as the
walkthrough for this pass. Inconsistency is visible in a grid and
invisible one screen at a time.

## Verification — evidence required

- Every FR exercised by a real person, not only by the agent.
- Every bug fixed, with its phase's acceptance list re-run and passing.
- The consistency contact sheet, with any fixes made from it listed.
- Confirmation that nothing was added to scope.
