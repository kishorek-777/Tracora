# /p15 — Deployment and handover

4 dev-days. Depends on P14.

## Read

`docs/LLD.md` deployment section. NFR-04, FR-90.

## Do

1. **Confirm production's branch alignment has not drifted** since P1.
   If the live server's `bench version` was never actually verified
   during this build, close that gap **before** installing, not after.
   Report what it says.
2. **Install** on the live bench — `bench get-app`, `install-app`.
3. **Smoke test on production**: register a test asset, assign it,
   unassign it, print its label, delete the test data. Confirm each
   step and confirm the cleanup.
4. **Scheduler verification** (FR-90): confirm the daily job is
   actually registered and running — check `last_reminder_run` updates
   on its own after 24 hours. That it exists in code is not evidence
   that it runs.
5. **Label stock and printer** — hardware, outside the agent's reach.
   Flag as a manual task for whoever owns physical setup, and confirm
   the printed output matches P7's measured sample on the real printer,
   not the test one.
6. **Handover document** — written for an operator, not a developer.
   Cover: registering an asset, assigning and unassigning, what
   happens at employee exit, printing and reprinting labels, reading
   reminders, and where each report lives. Short, screenshot-led,
   no FR numbers. Reuse the walkthrough screenshots from earlier
   phases — they already show real screens with real data.

## Verification — evidence required

- `bench --site <production> list-apps` showing `tracora`.
- The smoke-test sequence, each step captured, and the test data
  confirmed removed afterwards.
- `last_reminder_run` on production advancing across a real day
  without intervention.
- A photograph of a label printed on the production printer, measured.
- The handover document, and confirmation someone other than the
  developer has read it and could follow it.

## Final gate

Cross-check the full 92-FR list in `docs/PRD.md` **as a whole
document**, not phase by phase. Phase-local passes can each be true
while something that spans phases has quietly broken. List any FR that
cannot be demonstrated on production today.

Tracora is built when that list is empty — not when P15's tasks are
ticked.
